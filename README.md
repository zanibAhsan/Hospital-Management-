# Hospital-Management-
C++ Hospital Management System using object-oriented programming, file I/O, and patient/doctor record management with search and assignment features.

Features:
- Manage patient and doctor records
- Load patient information from `patients.txt`
- Load doctor information from `doctors.txt`
- Search for patients using their unique ID
- Search for doctors using their unique ID
- Find the oldest patient
- Count patients with a critical condition
- Display doctors by specialty
- Display a patient's assigned doctor
- Display all patients assigned to a specific doctor
- Calculate doctor salaries including performance bonuses
- Determine patient status based on diagnosis
- Input validation and error handling through a menu-driven interface
